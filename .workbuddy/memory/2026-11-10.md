# 2026-11-10

## 新建 scanaddr 项目并产出 IPA

- GitHub 仓库：`latinsundon24/scanaddr`（public），本地工作区 `F:/scanaddr`。
- 应用：iOS 15+ SwiftUI + 纯 Swift `ScanCore`（无第三方依赖），XcodeGen 生成工程，GitHub Actions 编译未签名 IPA。
- 功能：URL 模板中任意位置多个 IP 变量（`{A}` / `{A:raw}`），IPv4 与 IPv6 均支持（单地址 / CIDR / 起止范围 / +N / 列表），另有端口与文本变量；笛卡尔积生成候选，URLSession 并发真实 HTTP 探测，按状态码与响应关键字判定可用，结果可复制。主机位 IPv6 自动加 `[]`，模板 `[{A}]` 遇 IPv4 自动去括号。

## 过程中发现并修复的问题

1. `macos-14` runner label 在当前 GitHub 账户下报 `The configuration 'macos-14-arm64-us-default' is not supported`，所有 job 会在调度前直接 cancelled（无任何步骤）。诊断确认 `macos-15`、`macos-latest`、`macos-15-intel` 可用，`macos-13` 一直排队。已统一改为 `macos-15`。
2. Swift 版 IPv4 CIDR 掩码错误：掩码按 128 位布局写到了 hi，导致 `192.168.5.2/30` 展开成 `0.0.0.0/30`。`prefixMask` 增加 bits==32 分支，掩码落在 lo 的 bit31..(32-p)。是 CI Swift 自检抓到的，本地 Python 参考实现无此问题。
3. 用 `strings` 检查优化后 Mach-O 里的 Swift 字符串常量不可靠（误报「核心未编入」）。改为校验 .app 包结构 + arm64 Mach-O；链接成功本身已证明 ScanCore 在产物中。
